# Dictionary of AI Coding

A set of short markdown entries that define the vocabulary of working with AI coding agents, ordered so a reader can learn it in sequence.

## Language

**Entry**:
One file in `dictionary/` defining a single term, with a `description`, a body, and a Usage dialogue.
_Avoid_: Article, page, definition

**Curriculum**:
The ordered list of Sections and the Entries in each, held in `internal/Curriculum.md`.
_Avoid_: Syllabus, index, table of contents

**Section**:
A numbered group of Entries in the Curriculum, such as "Section 3 — Tools & Environment".
_Avoid_: Chapter, module, category

**Learned**:
A reader's own mark on an Entry saying they understand it, kept only in their browser.
_Avoid_: Completed, read, done

**Map**:
The view of which Entries link to which, drawn from the links inside Entry bodies.
_Avoid_: Graph, network
